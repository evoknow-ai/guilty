# Changelog

All notable changes to Guilty are documented in this file.

## [3.8.0](https://github.com/evoknow-ai/guilty/releases/tag/v3.8.0) - 2026-08-18

### Added

- In-extension privacy disclosure and full public privacy policy.
- Chrome Web Store submission package and listing assets.

### Changed

- Removed the development-only manifest key from the distributable package.
- Prepared the release manifest and packaging workflow for Chrome Web Store review.

## [3.7.0](https://github.com/evoknow-ai/guilty/releases/tag/v3.7.0) - 2026-08-08

### Added

- Folded category cards by default, with individual expand controls.
- Open All and Fold All controls for category cards.
- Configurable current-week and last-week comparison colors by category.
- Links to Mohammed Kabir's X profile and EatSleepAI website on the Credits page.
- MIT License and repository changelog, linked from the Credits page.

### Changed

- Share images now resize dynamically to capture the complete report, including all visible categories, sites, and weekly comparison bars.
- Updated the credit to "Imagined By: Mohammed Kabir."

## [3.6.0](https://github.com/evoknow-ai/guilty/releases/tag/v3.6.0) - 2026-08-08

### Added

- Initial public release of the Guilty Chrome extension.
- Local-only website activity tracking with wildcard domain rules and categories.
- Popup reports, configuration tools, sharing, and Credits page.
