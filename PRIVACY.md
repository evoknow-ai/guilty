# Guilty Privacy Policy

Effective date: August 18, 2026

Guilty is a local-only Chrome extension that helps users understand how much active browsing time they spend on websites and in user-defined categories.

## Data Guilty handles

Guilty processes:

- Website domain names from pages the user actively views
- Time associated with active use of those domains
- User-created categories, wildcard domain rules, colors, and preferences

Guilty does not read or store page content, passwords, form entries, payment information, authentication information, or private communications.

## How data is used

This data is used only to provide Guilty's user-facing activity reports, category summaries, weekly comparisons, settings backup and restore, and shareable reports initiated by the user.

## Storage and transmission

All Guilty data is stored in Chrome's local extension storage on the user's device. Guilty has no backend service and does not transmit browsing activity, settings, or reports to the developer or any third party.

If the user chooses to share a report, Guilty copies a generated PNG to the clipboard and opens the selected social website. The user decides whether to paste and publish the image. Guilty does not upload it.

## Sharing and selling

Guilty does not sell, rent, share, or disclose user data. No humans review user browsing data because the developer never receives it.

## User controls and deletion

Users can pause tracking, disable tracking of uncategorized sites, adjust the idle timeout, export or restore settings, and permanently erase all tracking history from Guilty's Settings page. Uninstalling the extension removes its locally stored data through Chrome.

## Permissions

- **Storage:** Saves activity history and settings locally.
- **Website access:** Detects the active domain and local interaction signals required to measure active browsing time across websites. Guilty does not read page content.
- **Clipboard write:** Copies a report PNG only after the user clicks Share PNG.

## Changes

Material changes to this policy will be published in this repository and reflected by the effective date above.
