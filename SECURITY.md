# Security Policy

## Supported version

Security fixes are applied to the latest published version of Guilty.

## Reporting a vulnerability

Please do not disclose a potential vulnerability in a public issue. Use GitHub's **Report a vulnerability** option under the repository's Security tab to send a private report.

Include the affected version, reproduction steps, potential impact, and any suggested mitigation. You should receive an initial response within seven days.

## Privacy boundary

Guilty is designed to keep browsing history and settings in Chrome's local extension storage. A change that transmits browsing activity, adds analytics, or introduces a remote service should be treated as a security- and privacy-sensitive architectural change.
