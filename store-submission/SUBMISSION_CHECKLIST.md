# Chrome Web Store Submission Checklist

## Before upload

- [ ] Confirm `manifest.json` version is higher than every previously uploaded version.
- [ ] Test the unpacked extension in a clean Chrome profile.
- [ ] Confirm tracking, category assignment, settings, export, restore, history deletion, and Share PNG.
- [ ] Confirm the public privacy-policy URL opens without signing in.
- [ ] Confirm no personal browsing data appears in screenshots.

## Package

- [ ] Upload `guilty-3.8.0-chrome-web-store.zip`.
- [ ] Do not upload the repository ZIP or the full submission-kit ZIP as the extension package.

## Store listing

- [ ] Paste the summary and detailed description from `STORE_LISTING.md`.
- [ ] Category: Productivity.
- [ ] Upload `icon-128.png`.
- [ ] Upload at least `screenshot-1-weekly-report.png`.
- [ ] Upload `promo-small-440x280.png`.
- [ ] Optionally upload `promo-marquee-1400x560.png`.
- [ ] Add homepage, support, and privacy-policy URLs.

## Privacy practices

- [ ] Paste the single-purpose statement.
- [ ] Paste each permission justification.
- [ ] Declare web browsing activity.
- [ ] Confirm browsing data is not sold, shared, or transmitted off-device.
- [ ] Certify compliance with Limited Use requirements.

## Distribution

- [ ] Public visibility.
- [ ] All regions, unless a narrower launch is desired.
- [ ] No in-app purchases.

## Reviewer notes

- [ ] Paste or attach the relevant text from `REVIEWER_NOTES.md` if the dashboard offers reviewer instructions.
- [ ] Submit for review.

Google reported extended review times beginning in April 2026, so a review may take longer than usual.
